# Published 87-row predecessor

[CA_87_3_40_3.txt](CA_87_3_40_3.txt) is an unchanged copy of Bai XunDi's published
87×40 ternary strength-three array, supplied with the prior-art audit.
It comes from the original October 30, 2026 dataset, version 1.0,
DOI [10.5281/zenodo.23787055](https://doi.org/10.5281/zenodo.23787055).

SHA-256:


Bai's dataset builds on the Shokri–Moura construction lineage. The supplied audit
verifies this predecessor exhaustively and finds every row essential: each is the
unique witness for at least 25 interactions. The new 86-row matrix therefore
requires changes beyond merely deleting an unneeded parent row.
